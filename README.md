# ATM Management System 

##  Project Description
The ATM Management System is a beginner-friendly Python project that simulates basic ATM operations. It allows users to securely access the system using a PIN and perform simple banking transactions.

##  Features
- PIN Verification
- Check Account Balance
- Deposit Money
- Withdraw Money
- Exit the System
- User-friendly menu-driven interface

##  Technologies Used
- Python
- Conditional Statements (`if-else`)
- Loops (`while`)
- User Input (`input()`)
- Variables and Basic Operators

##  How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python atm management system.py
```

##  Project Objective
To understand Python fundamentals and learn how to implement basic banking operations using programming logic.

##  Learning Outcomes
- Improved understanding of Python basics.
- Practiced conditional statements and loops.
- Learned to handle user input.
- Implemented basic transaction logic.
