# Railway Reservation System Using Python

## Project Overview
The Railway Reservation System is a Python-based project developed as part of Python programming lab exercises. This project demonstrates the implementation of basic Python concepts through railway reservation-related examples such as passenger details, train information, ticket booking, seat availability, and PNR validation.

The main objective of this project is to understand and practice Python programming concepts using a real-world railway reservation scenario.

## Objectives
- Understand Python programming fundamentals.
- Work with variables, data types, and operators.
- Implement conditional statements and loops.
- Manage passenger and ticket information.
- Understand lists, dictionaries, and functions.
- Apply object-oriented programming concepts.
- Perform PNR and seat validation using regular expressions.

## How to Run the Project

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   `pip install requests beautifulsoup4`

4. Open Jupyter Notebook.
5. Open the file **Railway Reservation System Lab .ipynb**.
6. Run the cells one by one to understand the implementation and output.
